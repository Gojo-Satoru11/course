What is CSS?

CSS is an acronym of 'Cascade Style Sheet' it is used to make some styles, decorations your website, you can apply CSS styles by one of the following:

  1. inline styling
  2. internal styling
  3. external styling

and the prefered way to apply styling is the external styling because you can use one file for 2 or more HTML document and you can use many styling properties in it such as 'backgound-color' or 'font-size' and here's a video below for further explanation 👇
